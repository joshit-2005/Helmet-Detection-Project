# Helmet-Detection-Project
Basically to detect the helemt from the input image 
Download the Vs code for Running Pyhton files and use the python 3.10 version to support tensorflow
Create a vitual environment to run the files 
then install all the modules in the requirements.txt
You need to train the model for that need to run the train_helmet_model.py
we get model.h5 files one can change the parameters during training to get good results
once the model is trained and obtained the h5 file we can execute the app_trained.py file which uses flask to display the option to upload the image 
dont confuse that there are two such files , i.e to use the two models i have used different files
